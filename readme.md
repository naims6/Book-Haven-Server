# 🧠 The Book Haven - Backend

This is the **backend API** for [The Book Haven](https://thebookhaven-c1738.web.app/).  
Built using **Node.js**, **Express.js**, and **MongoDB**, it powers all book-related data operations, authentication, and user interactions.

---

## ⚙️ Tech Stack

| Category                   | Technologies         |
| -------------------------- | -------------------- |
| **Runtime**                | Node.js              |
| **Framework**              | Express.js           |
| **Database**               | MongoDB Atlas        |
| **Authentication**         | Firebase Auth        |
| **Environment Management** | dotenv               |
| **Others**                 | CORS, date-fns, etc. |

---

## 📦 Features

- RESTful API for managing books
- CRUD operations (Create, Read, Update, Delete)
- User-based permissions (only creator can edit/delete own books)
- Comment system for each book
- Sorting and filtering support
- Timestamping with date-fns
- Secure CORS and environment-based config
